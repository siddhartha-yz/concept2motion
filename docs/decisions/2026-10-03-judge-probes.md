# 事实裁判的新对照包（只准备本地刺激）

v3 出现两种附件顺序不一致，且普通自查在一个技术未通过的配对中仍获画面偏好。
不能因此认定裁判错，也不能把技术通过当成画面真值。

新包只检验三个可由程序核对的画面事实：修正尾端是否接到输入头端、
指数条是否与标出的指数质量成比例、输出箭头是否表达完整的带符号和。
每个事实两份正确图形（改变布局/尺度）与两份负对照（改单个几何因素或移除图形）。
数值、正确文字和抽帧时间保持可比；标题和 ID 不泄漏条件。

这些不是艺术参考。它们不能给“更好教学/更美”的全局标签；仅给支持/矛盾/无图可验证的事实标签。
原始真实视频、抽帧、源码、独立数值真值、渲染结果在调用前冻结。

本次仅生成/渲染本地控制，不发给模型；不会占用 v3 已用完的 24 次授权。
未来外部筛查须另行授权。正负分开记录漏检、误报和未知，不能只报总通过率。
参考 MM-JudgeBias 与 D3-Omni 的原子干预/正负平衡思路，但不声称复现其数据或指标。
