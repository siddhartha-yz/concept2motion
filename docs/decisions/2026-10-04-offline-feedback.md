# 无新模型额度时的最小下一步

状态：设计冻结；事实筛查、表达评分和跨概念收益仍未验证。

## 先解决哪一小块

按“可信评分 → 评价驱动修改 → 未见任务对照”推进。优先复现对象仍是已记录的 Code2Video / TeachQuiz；不新造艺术总分，也不在无调用预算时伪造论文评价结果。

本轮先为已有 v3 事实包增加**只导入、不调用模型**的入口：检查冻结文件与实际刺激哈希，核对响应身份、供给时刻、帧哈希、对象和具体观察，分开统计正确标签、错误标签、证据不足、格式错误、请求失败及缺失。按三个事实和三个真值类别报告分母。结构与哈希校验不能判断观察内容真实，更不能证明裁判可靠。

下一步做确定性技术反馈循环：复用已渲染的手写控制，给出人工写定的缺陷票据和精确补丁。重新导出修改前后视频，验证目标缺陷消除、没有新增检查代码、保护时刻的整幅抽帧字节不变。保存候选版本；失败只让活动版本指回基线，不删除失败。一次票据仅一次补丁、两次渲染，无模型调用、无自动重试。

这一步连接的是**技术检查 → 人工原因假设与补丁 → 自动重渲染/决定**。没有外部裁判自动定位，没有模型生成补丁，没有艺术质量自动验收。保护的是指定的完整帧和精确源码编辑，不声称通用对象/连续时间保护。
