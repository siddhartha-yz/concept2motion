# 2026-10-10：先做好教材到可视化教材

这是用户与维护会话讨论后的方向记录，先于本轮 D2L 生成实验写入。旧实验的结果和失败保持原样。

## 用户实际试读给出的修正

用户试读 `reading-textbook-v1` 后认为效果不好：图内文字过多，与正文重复，并挤占阅读注意力；相比光标跟随，更喜欢按阅读位置推进。原先的浏览器检查只支持工程可运行，不能升级为阅读体验或学习效果通过。

据此调整：正文保留推理和严谨说明；图只呈现难以直接从文字看出的关系。短标签、数值和轴名按需留下，不把段落再次塞进图。默认安静、无持续自动播放，阅读推进是粗粒度线索，不能宣称知道眼睛在哪里。允许回读、跳读、暂停和参数探索。

## 五份参考与借鉴范围

- [Bartosz 的机械表](https://ciechanow.ski/mechanical-watch/)：段落内插图、颜色对应、逐步拆解复杂机制；不照搬持续运动。
- [Red Blob 的 A*](https://www.redblobgames.com/pathfinding/a-star/introduction.html)：每幅图只解释当前问题，正文、算法、代码和操作相互对应。
- [Distill 的感受野](https://distill.pub/2019/computing-receptive-fields/)：保留数学推导，图呈现参数之间的关系。
- [Georgia Tech 的矩阵变换教材](https://textbooks.math.gatech.edu/ila/matrix-transformations.html)：完整教材中定义、例子、图和练习的组织方式。
- [R2D3 的机器学习入门](https://r2d3.us/visual-intro-to-machine-learning-part-1/)：借鉴滚动推进机制，不照搬左右分栏。前次浏览器加载超时，原文读取成功。

用户已读完五份，认为均值得借鉴。它们是设计参考，不是本项目学习收益的证据。

## 两部分分开

1. `movie2textbook`：视频、音频和课程材料变成教材。已有 Video2Book 等可借鉴实现，暂不作为这轮瓶颈。
2. `textbook2visualbook`：已有教材变成包含适量静态图、交互图和变化的 HTML 教材。本轮聚焦这里。

前一轮“缺原生听音通道”指会话未接入上游要求的 `read_audio` / `read_media` 工具，不表示 GPT 或 OpenAI 没有音频模型；音频接入的缺口不应阻碍后半部分实验。

## Zanim 的位置

用户同意：HTML 教材是主体。SVG、Canvas、JavaScript 或 Zanim 可按图形需要选择。Zanim 已验证可跳到指定图形状态，但没有对照证明它更适合整本教材或稳定批量生成。不将它规定为所有图形的底座，不将所有阅读关系强行换成时间轴。

旧项目的可复现渲染、具体证据、局部修订和失败保留值得复用。旧视频生产、统一评分和庞大代理框架不自动继承。

## D2L 实验原则

使用用户熟悉的中文 [D2L 第二版](https://zh.d2l.ai/)作为第一批教材，便于用户审查。D2L 本来已有公式、图和可运行代码，比较对象是原版，不是删掉图的文字版。

- 候选节及可视化理由在生成前登记。不同知识类型轮流覆盖，类型内随机选，保留随机种子和源版本。
- 以一个独立节（例如 6.2）为单位，保留完整相关正文、公式、代码和上下文，不只做一张独立图。
- 抽到困难章节不能偷偷重抽；失败、首版、修订和维护者手改都进入账目。
- 随机新节检查适应能力，少量旧节检查退步；D2L 内部表现稳定后才讨论跨教材推广。
- 内容正确、阅读体验和生产稳定性分别判断。用户熟悉教材有助于事实审查，但不能代替初学者学习效果实验。
