# 待解决：怎样给动画一个可信的评价分数

状态：**未解决；已验证离线入口和固定评分代码的故障反例，尚无新的真实裁判结果。**

记录日期：2026-10-03。

## 用户指出的问题

我们要判断这套工具是否让小模型生成的动画更好懂。目前报告主要列出成对胜负，却没有一个经过验证的单视频评分方案。不同方面有冲突时，例如箭头关系更清楚但文字更难读，最终取舍仍由模型综合决定。

用户希望优先采用有论文依据、明确计算公式、公开实现和可信验证的现成标准，避免自行设计一个分数，再用这个分数证明自己的工具有效。

## 当前评价能说明什么

- 现有实验让强模型比较匿名抽帧，交换顺序后复评；判断不一致和缺视频分别保留。
- 相对胜率为 `(胜 + 0.5 × 平局) / (胜 + 负 + 平局)`，同时报告有明确结果的比较占全部比较的比例。
- 最新一轮各胜一组，另外一组未决、一组缺视频；没有证明稳定提升。
- 这是模型的相对偏好，不能当作单视频质量分数或人类看懂率。
- 渲染成功、程序检查通过、数学正确、讲解易懂和艺术完成度是不同结果，不能混为一个通过率。

## 已找到的现成标准

| 标准 | 明确公式或评分方式 | 需要注意的限制 |
|---|---|---|
| Code2Video / MMMC / TeachQuiz，ICML 2026 | 知识增益 = 看视频后答题正确率 − 要求学生模型忽略原有知识时的正确率；另有五项画面评分 | “忽略知识”采用提示词，模型先验可能影响结果；自动答题不是人类学习效果 |
| TheoremExplainBench，ACL 2025 | 五项归一化分数的几何平均：准确性、视觉相关性、讲解顺序、布局、一致性 | 人机相关性因维度而异，准确性与讲解顺序较弱；原流程使用字幕和视频片段 |
| PhyEduVideo，WACV 2026 | 教学点的语义匹配、物理正确性、运动平滑与闪烁分别评价 | 有 500 个视频的人类验证，但物理短视频上的验证不能直接外推到数学图解 |

详细公式、论文链接、验证数据和公开实现见[现成标准核查](../../evaluation/2026-10-03/published-metrics/REPORT.md)。这些标准尚未在本项目完成独立复现。

之前提出的 `100 × 清楚展示的必讲要点数 / 必讲要点总数` 是自定义的解释完成度指标。它只用于诊断缺失步骤，没有经过人类评价验证，不作为主要质量结论依据。

## 解决这个问题需要交付什么

1. 明确主评价究竟测量什么：概念传达、画面质量或其他目标；选择对应的论文标准，记录选择理由。
2. 固定上游版本、题目、评分提示、公式、采样方式、失败处理和模型调用预算，在生成前保存。
3. 用独立样本复现评价流程，并检验已知正确、图文矛盾和没有有效画面的样本；保留误判和无法判断。
4. 若使用 Codex 订阅替换论文裁判，或把完整视频改成抽帧，明确记录改编，并重新验证可靠性。不能直接继承论文的人机一致性结果。
5. 报告分数、样本量、失败率、裁判一致性与不确定性，再在同任务、同预算条件下比较普通生成与工具辅助生成。公式本身不能证明评价有效。
