# 未见任务对照：只准备，尚未启动

准备了 3 个不同概念结构：[任务清单](tasks.json)。它们不是 Softmax / 残差题换数字。对已跟踪的 benchmarks、docs、evaluation 文本和场景源码做关键词检索，没有发现上述三种任务已有本地生成/修订实验；检索不证明模型预训练未见，也不证明隐含语义完全不重叠。

**尚无候选、渲染或质量结果，实验模型调用 0，授权预算 0。** 清单公开且当前维护会话看过，因此它是后续持出任务的准备文件，不是封存盲测集。后续不得先用这些题调试，再继续称它们未见；任务有泄漏或被用于调试时须登记并替换。数学真值仅为以后核验的目标，当前图形检查器均未实现。

启动前的依赖，按顺序完成：

1. 先对固定 v3 事实刺激执行另行授权的外部筛查，保留错误、未知、失败及分母。格式有效和程序真值不能单独建立评分可信度。
2. 在本项目独立复现/验证 Code2Video / TeachQuiz 优先路线，明确视频/字幕/抽帧、题目和模型替换差异；锁定主评价、局限与最小改善阈值。当前没有选定可用于效果宣称的主评分。
3. 将技术票据扩展到经过验证的画面反馈，使用 AI 生成修改假设/补丁；保留每次检查与回退。当前仅有人工票据和补丁的技术切片。
4. 运行前新建完整实验计划，固定作者与裁判版本、题目/风格、共享调用与 token/时间上限、修订次数、失败处理、所有费用和停止条件。用户需另行授权新额度；旧预算不继承。

完整工具比较：同一个作者模型、同任务/输入，普通生成修订与工具循环配对。普通组可正常使用 helper、自查、运行错误和同等预览。反馈评审、修订、复评均计入工具组总成本；相同调用次数不代表相同 token 成本。最终评测上下文不含组别/反馈/补丁来源，也不将结果回流修订。独立上下文不消除共享模型偏差。

先做 3 个独立任务的探索对照，逐任务报告配对差异、失败和不确定性；重复裁判/交换顺序不增加任务样本量。小样本不能给稳定跨概念收益结论。局部预览速度、技术导出率、数学检查和论文分项/知识增益分别列出；组件消融与强模型参照是另一个实验，不混入完整工具效应。

本文件没有预注册一个可立即运行的质量实验：主评价可靠性、最小改善阈值和新预算仍缺失。先把这三项缺口补齐，不能用本轮 7 个技术控制当作未见任务质量对照。
