## 数学核对与失败保留

共享内核默认值 p=(0.665240956,0.244728471,0.090030573)，真实类别鸡时 g=(0.665240956,−0.755271529,0.090030573)，η=0.5时损失1.407605964 → 0.946687688 nat。

verify_math.py 另用独立 Python 中心有限差分验证三类标签下9个导数，最大误差约1.2e−10；检查12组共同平移与固定概率比，以及12组标签/步长损失。完整结果在 math-verification.json。另从代数上核对：softmax比值为 exp(o_j−o_k)，共同平移因子抵消；损失导数为 p−y，梯度和为零。有限步长核对仅适用于记录的示例，不能泛化为任意训练稳定性。

保留失败：softmax-loss 首次误传独热标签（内核要求整数类别标签），随后改为[1]成功；两次补充构建因 id 没有 note- 前缀被拒绝，修正计划后成功构建。失败记录与 builds/build-001、002 保留。可选浏览器检查因 iab 不可用而失败；正式PNG预览不受影响。
