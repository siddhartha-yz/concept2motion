# 参数修改真正移出源码

首轮同模型试验没有端到端提速。本实验继续使用其 Infra 模型候选，**明确做了一次源码适配**：把两个旋转区间注册为命名动作，绘制函数改读注册返回的区间。原始与新源码哈希、完整替换记录见 adapter.json；没有调用模型生成另一候选，人工适配耗时未测量，不能算零。

适配后 baseline 与原候选的 9 张样本 PNG 字节一致。接着仅修改 `timing.json`，把第二次动作从 5.2–7.2 改成 4.85–6.85 秒。绘图源码在 baseline、earlier、故障注入和恢复版本中保持同一个 SHA-256。

| 实际操作 | 耗时 |
| --- | ---: |
| 参数文件产生新版本 | 0.000785 秒 |
| 参数修改到 4 秒局部 MP4 可用 | 0.864568 秒 |
| 故意注入无效区间被拒绝 | 0.098460 秒 |
| 故障到回滚并恢复抽样预览 | 0.337650 秒 |
| 恢复样本预览本身 | 0.234128 秒 |

上述计时使用一个常驻浏览器，浏览器启动另列 studio.json。全实验新增模型调用 **0**。两条实际视频通过独立完整解码和媒体参数核对，见 audit.json；恢复只做样本，状态是 samples_ready，未导出恢复视频。

96 个局部帧的角度轨迹符合整体提前 0.35 秒，区间外样本像素保持一致。回滚后的所有样本与前一个有效版一致。非法区间是**故意注入的 fixture**，回滚采用已知有效配置，不是自然生成失败，也不是 AI 发现并修好了艺术问题。

这个结果支持：已生成且绑定动作的场景可以快速调整时序、拒绝坏参数并恢复上一版。它不支持：新场景生成比直接提示词快、美术更好、完全无人审看，或任何自然语言修改都能变成参数。Direct 自行采用同样参数化也可能获得收益；收益来自可执行的动作边界，不能凭库名字归因。

审看记录：baseline 未改变所抽样画面，旋转与残影仍可跟踪；来源候选的用户艺术接受待定。本实验只检验时序修改，不宣称审美提升。input brief、来源、适配、四个版本源码、渲染与抽样状态、代数与媒体证据、修改历史均保留。
