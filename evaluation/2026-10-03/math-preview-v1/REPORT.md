# 原生数学候选的常驻局部预览

这次是本地预览工具的验证，不是模型生成能力试验。使用两条 v3 的原始模型候选源码、冻结正负对照，零新增模型调用。输入、源码副本、工具哈希、抽帧、检查及失败结果均保存。

常驻 Chromium 启动约 0.340 秒（单次）。

| 操作 | 实际总耗时 | 结果 |
|---|---:|---|
| Softmax 4 个抽帧 | 0.346 秒 | 指定样本检查通过，没有视频 |
| Softmax 13–15 秒，24 帧 | 0.444 秒 | 草稿编码、完整解码；局部检查通过 |
| 残差 9–12 秒，36 帧 | 0.505 秒 | 草稿编码、完整解码；局部检查通过 |
| 未完成渐显 13.5–18 秒 | 0.694 秒 | 草稿仍可看，独立检查捕获未完成错误 |
| 像素覆盖负对照 | 0.135 秒 | 抽帧捕获 pixel_mismatch |
| 注入绘图异常 | 0.093 秒 | 失败输出保留 |
| 异常后的正常请求 | 0.177 秒 | 服务器继续工作、样本检查通过 |

时间包含源码冻结、页面加载、取帧、采样、JPEG seek 核验及编码（如适用），不包含模型生成、创作修订或人工/模型审看。队列耗时另记；测量来自本机少量操作，不是稳定 p95 或跨机器性能承诺。三个实际视频均核验帧数、960×540、12fps并完整解码。

输出永远是 preview_ready/samples_ready，不能获得整片 render_passed 或艺术接受。检查只覆盖请求片段、指定样本与 seek 探针，不验证完整阶段覆盖。不可核验的像素探针单独记录。

第一批测试记录器误把 Fetch Response.status 属性当函数；第二批误在 settledAt=17.1 之前检查“未完成”负对照。两批原输出保留在 ignored work/math-preview-smoke-v1、v2。第三批修正测试记录和取样窗口，不放松检查器；通过预先记录的七个场景。

旧雪花命名时序的真实浏览器回归也通过，记录 work/legacy-studio-after-math-v1；包括未改区域像素一致、无效区间拒绝、服务恢复。它是旧功能回归，不是新的艺术实验。
