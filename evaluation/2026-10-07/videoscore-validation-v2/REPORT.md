# VideoScore适用性实测：不能作为概念讲解的核心裁判

**实际结果：能对明显内容错配降分，却不能稳定区分数学几何和讲解步骤的缺陷。暂不接入自动保留/回退或训练奖励。**这是本项目三个概念的适用性结论，不宣称它在所有视频任务上失效。

## 我们具体测了什么

固定VideoScore v1.1官方约8B权重，原Mantis实现、处理器、五维提示和48帧均匀采样。沿用BF16及GPU/CPU分配，无量化、训练或更换模型。先冻结输入与判断规则，再运行39次本地前向：36个首次输入条件、重新加载后的3个重复，39/39完成，评分阶段无失败或遗漏。

36个条件包含：三个概念各七版本（21个编码文件，其中三个灰屏内容相同，故19个视频哈希）；既有事实包10个唯一视频；Manimator修改前后两个视频；同三个正确视频换无关提示。合计31个唯一视频内容。重复和共享基线不增加独立概念数；只有行列式、Softmax、残差相加三种概念。

| 工作层次 | 本轮证据 |
|---|---|
| 安装检查 | 使用先前已核验环境和15个模型文件；两次正式加载核验源码/权重哈希 |
| 模拟测试 | 没有模拟评分；控制干预和真值由手写脚本确定 |
| 实际渲染 | 两版各21个8秒控制视频；采用的第二版1344帧全部解码，854×480、8fps已独立核对 |
| 真实模型生成 | 本轮0次；手写控制不是模型生成。Manimator两版来自既有真实生成/补丁记录 |
| 真实权重评分 | 39次原预训练模型前向，真实logits/输入张量/抽帧哈希保留 |
| 艺术及学习评价 | 维护者看三个概念七版本的三时刻画面，核对干预；没有人类艺术、可读率、学习效果或总体质量标注 |

## 分开看每类缺陷

每类三对，分别来自三个概念。主要维度和方向在评分前固定。方向吻合数 / 3 = 对照中正确版原始分数严格较高的数量 / 三个概念对照；平局不算吻合，分数反向也保留。这是诊断方向，不能叫缺陷识别正确率或质量通过率。

| 干预 | 方向吻合 | 平局 | 反向 |
|---|---:|---:|---:|
| 错公式 | 2/3 | 1 | 0 |
| 错几何 | 0/3 | 1 | 2 |
| 缺讲解步骤 | 0/3 | 2 | 1 |
| 小字 | 2/3 | 0 | 1 |
| 闪烁 | 2/3 | 1 | 0 |
| 空白画面 | 3/3 | 0 | 0 |
| 无关提示 | 3/3 | 0 | 0 |

错公式/错几何主要比较事实一致性；缺步骤、空白和提示错配看文字对应；小字看画面质量；闪烁看时间一致性。没有事后改用另一维度或五维平均救结果。数学真值用独立行列式/鞋带面积、指数归一化、分量相加核对；不是模型自打分。

三个错几何对照均未给正确版更高事实分：两对反向，一对平局。三个缺步骤对照也均未按预期区分。小字、闪烁只在各两对出现预期下降，不能说稳定测量可读性或运动质量。

## 可以直接复查的反例

行列式正确版的事实分为2.4375。把目标公式+2改成-2，仍是2.4375；把最终有向面积从2画成1.5，事实分却升至2.5000。残差相加漏去过程，仅展示终态时，文字对应从2.203125升至2.21875。

既有控制不是全部支持或全部失败。四对错误/不完整几何中：2对方向吻合、1对平局、1对反向。例如Softmax正确比例B8与错比例K6的事实分同为2.421875；残差正确Q7为2.4375，错误目标S3为2.453125。两个缺图对照：残差方向吻合，Softmax反向。有效缩放只作观察，不伪造一个预期艺术排序。完整值见[分析](analysis.json)。

空白版使用与对应正确版完全相同的概念任务要求；文字对应均下降，差约0.336–0.391。对同一正确视频换成猫在雪林行走的无关提示，三对均下降，差约0.703–0.883。检查确认错配输入的像素张量相同、文字token不同；错公式输入像素张量确实改变。这支持“这批样本的明显内容错配有响应”，不外推一般可靠性。

## 重复和实际修改

重新加载同一权重后，三个正确视频的48帧哈希、处理器张量哈希与分数均一致，最大绝对分差0。稳定重复不等于正确判断；这里只有三例、一个设备和同一环境，没有一般误差分布或显著性估计。原始BF16回归值保留，微小分差不被解释成人类能够感知的改善。

Manimator首版/修订版五维分数分别为：

| 版本 | 画面 | 时间一致性 | 动态 | 文字对应 | 事实 |
|---|---:|---:|---:|---:|---:|
| 首版 | 2.734375 | 2.500000 | 2.453125 | 2.218750 | 2.593750 |
| 修订版 | 2.718750 | 2.468750 | 2.437500 | 2.218750 | 2.562500 |

时长和TARGET标签的技术修改已由独立检查确认，但这里四维下降、一维持平。没有整段质量人类真值，所以不能说评分排序一定错，也不能说修订的艺术质量下降。它没有直接表达我们验证的具体修改目标。

## 资源、失败与限制

39项单次执行墙钟累计636.356秒（包括每项视频处理、哈希/抽帧和前向；不含下载安装、控制渲染、权重加载与报告）。最高GPU已分配8.433GiB、保留10.428GiB，CPU分担权重；不是完整GPU装载或训练能力证明。官方Codex新增调用0次，原96次账仍58次尝试、54完成、4未知、38剩余。没有云算力或付费API。

评分前的输入歧义、编码检查误报、过早提交标题、GPU沙箱限制、抽帧目录冲突和错误返回0都在[v1失败报告](../videoscore-validation-v1/REPORT.md)保留。这些启动没有评分前向；本版仅修证据路径和失败返回码，同一冻结刺激没有因分数结果被修改。

限制：三概念、有限手写干预；无陌生任务总体质量盲评；只有最多48个样本帧，未证明每帧都被理解；未复现官方约7000视频基准或0.74人类相关性；没有训练本项目权重。领域迁移可能解释失败，但原因未隔离。原研究范围见[来源](SOURCES.md)。

## 使用决定

**不采用VideoScore v1.1作为本项目的数学验收、讲解完整性判据、自动修改取舍或训练奖励。**保留它作为可复查的研究对照；明显内容错配可继续研究，但本轮不足以设定自动筛选阈值。主线继续独立数学/几何检查与经过任务内控制验证的画面反馈。
