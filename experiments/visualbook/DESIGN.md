# D2L 第一轮：生成前的约定

抽样在任何新图编写前完成，见 `sampling.json`。种子为 `16735797085957599960`，四类各从四节随机选一节，下一项留作后续新样本。选中了汇聚层、随机梯度下降、注意力评分函数、多 GPU 训练；不会因结果难看而换题。

## 这一轮做什么

帮助模型从原文确定“这里值得有一幅图”的位置，生成原生 SVG/JavaScript 图解，再把图插回完整阅读流。正文不由模型重写。默认图不自动播放，不监听鼠标，不要求翻页，不使用左右两栏。滚动只提供粗略位置，图仍能手动探索，回读时能恢复对应状态。

每节最多两幅新增图；每幅解决一个具体理解障碍。避免图中重复正文，保留短标签、轴、数值和必要的实验假设。优先由同一份数值计算驱动形状和数值标签。形状、公式和颜色不是任意装饰。

模型可自由编写 `render({width,state,params})`，返回 SVG 和便于检查的数值。框架只规定原文锚点、状态绑定、可选参数和返回接口，不规定知识图形类型。Zanim 不作为依赖。窄接口的目的在于可嵌入、可静态导出和可局部修订；如果限制了必要表达，应记录并修改接口。

原文从固定 D2L 提交导入，保留原图、公式、PyTorch 代码、练习和来源。上游源码无 notebook 执行输出，本轮不会伪造原版输出。导入适配单独记录，不能把排版成功称为教材事实正确。

## 首版与修订如何记账

官方 Codex CLI 串行运行，使用已有 ChatGPT 登录，不取出凭据。每次调用有独立输入、结构化输出和本地事件日志。生成会话不能读维护仓库、运行工具或联网；完整上下文由输入提供。原始提示、事件、截图保存在忽略的 `raw/`，公开记录保存哈希、计时、使用量与错误摘要。首版不覆盖。

初版提示相同设计规则、原文与可引用锚点，不提前给该节手写最终图。维护会话进行独立数学检查、桌面与窄屏实际渲染、回读/跳读/键盘/静态阅读检查，再提供具体修订意见。维护者改图与独立 CLI 修订分开记录。浏览器成功不是艺术审查通过；无标签遮挡也不是解释有效。

本轮最多八次实际生成/修订调用；遇连续三次服务失败停止无意义重试。这个上限是维护者控制本轮范围的约定，不是用户额度承诺。用户可随时取消。

## 会据什么判断

- 内容：计算及关键因果关系是否与原文一致；额外例子是否明确标为手选参数，是否避免过度推广。
- 阅读：图是否解释正文没有直接展示的关系；图中文字与正文是否重复；窄屏是否仍可读；滚动是否打断阅读或让图乱跳。
- 生产：四节中多少首版能导入、多少数学正确、多少经维护审查可供真人试读；修订次数、人工修改与失败均保留。
- 稳定性：原文锚点/哈希失配时停止插入，不猜位置；运行失败仍保留完整正文和静态图；输出离线可读。

四节是探索性案例，不能用作稳定批量生产的充分证据。没有真人阅读实验时不宣称学习效率提高。本轮的价值还包括找出可以直接改善下一次生成的规则与反馈方式。
