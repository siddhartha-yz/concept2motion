# 教材到可视化教材

这个实验帮助 LLM 为已有教材编写段落内图解，并将真实生成、实际渲染和修改记录放在一起。它独立于旧视频作者／评分流程；Zanim 是可选技术，不是输入协议的前提。

方向与试读反馈见 [讨论记录](../../docs/decisions/2026-10-10-visualbook-direction.md)。本轮执行日志见 [D2L 实验日志](../../evaluation/2026-10-10/d2l-visualbook-v1/LOG.md)。

第三方教材及依赖放在忽略的 `work/visualbook/`，输出放在忽略的 `outputs/visualbook/`。公开源码、来源定位、生成提示、摘要与修改证据；不将完整教材或敏感模型日志加入 Git。

当前正在实现。本文件随后补充实际可运行入口和边界。
