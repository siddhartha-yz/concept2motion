# Identity survives

- 0–2.8 s: three signed components of x, with a visible zero mark.
- 2.8–6.2 s: x travels on the upper identity path without changing magnitude or sign. The lower F(x) path shows the illustrative correction values. Colors identify corresponding components.
- 6.2–9.2 s: the correction arrows move to each identity endpoint; signed displacements join head to tail.
- 9.2–12 s: a bright arrow below each joined pair shows the component sum. The second component remains negative after near cancellation; the third shrinks because its correction is negative.

All lengths share the same units. The correction is hand-selected, not a learned network computation. The intermediate motion is choreography between fixed mathematical states.
